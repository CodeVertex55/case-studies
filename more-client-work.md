# More client work

Sites I built as a freelance developer for [Reign Media](https://reignmedia.com.au), a marketing agency in Perth, Western Australia. They cover Webflow, Shopify, WordPress and a custom web application. Each entry is short: what the site is, what it runs on and where to see it. Full write-ups of other projects are in the [index](README.md).

## Dave & Buster's Perth

![Dave & Buster's Perth home page](assets/dave-and-busters/hero.png)

| | |
|---|---|
| Industry | Entertainment venue, Clarkson, Perth |
| Platform | Webflow |
| Live | https://www.daveandbusters.au |
| Role | Freelance developer for Reign Media |

The Australian site for the arcade, dining and sports bar venue. It has a page for each reason to visit (eat and drink, play, watch sport, functions, parties), a what's-on section, online bookings and gift cards.
